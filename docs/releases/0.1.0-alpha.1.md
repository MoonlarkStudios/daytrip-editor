# Dosty 0.1.0-alpha.1

First packaged alpha of Dosty, a native Markdown editor built with Rust and Iced.
Write with live formatting, tables, images and themes, or switch to Markdown source.

## Downloads and installation

- **macOS:** choose the `arm64.dmg` for Apple silicon or `x86_64.dmg` for Intel.
  Open the disk image and drag Dosty into Applications. The builds target macOS
  12 or newer. They are ad-hoc signed, without Developer ID signing or notarization.
  After attempting to open the app, use System Settings → Privacy & Security →
  Open Anyway where allowed; see [Apple's instructions](https://support.apple.com/en-us/102445).
- **Windows:** run the x86_64 setup EXE. It installs for the current user without
  requiring administrator privileges. The installer and application are unsigned;
  SmartScreen warnings are expected and some security policies may block them.
  See [Microsoft's explanation](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).
- **Debian/Ubuntu:** install the amd64 DEB with `sudo apt install ./dosty_*.deb`.
  The build baseline is Ubuntu 24.04; Ubuntu 24.04+ and Debian 13 are initial
  targets for native testing.
- **Fedora:** install the x86_64 RPM with `sudo dnf install ./dosty-*.rpm`.
  The build baseline is Fedora 43; Fedora 43+ is the initial RPM target.
  Other RPM distributions are not yet supported.

Use the system package manager for Linux dependencies. File dialogs need a
working desktop session, D-Bus and a desktop portal backend; Zenity is installed
as a fallback. Packages include launcher icons and licenses. Source matching this
release and `SHA256SUMS` accompany the downloads.

## Known limitations

This is an experimental alpha. Native screen-reader support is incomplete and
remains a blocker for a general release. Real CJK composition, bidirectional
editing and Windows/Linux desktop workflows need more native testing. Recovery
may lose edits since the last checkpoint; keep backups of important documents.
See the [current release gaps](https://github.com/MoonlarkStudios/dosty/blob/v0.1.0-alpha.1/docs/evaluation.md#remaining-release-work).

Build checks and package inspection do not establish full desktop compatibility.
The release stays a draft until a maintainer reviews the workflow results and
manually tests the actual downloaded packages. Record the tested OS versions and
results here before publishing. Report reproducible problems through
[GitHub issues](https://github.com/MoonlarkStudios/dosty/issues).
